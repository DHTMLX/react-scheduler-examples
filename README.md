# React Scheduler Public Examples

[![dhtmlx.com](https://img.shields.io/badge/made%20by-DHTMLX-blue)](https://dhtmlx.com/)

> Standalone public showcase demos for the [DHTMLX React Scheduler](https://dhtmlx.com/docs/products/dhtmlxScheduler-for-React/) wrapper.

- Documentation: https://docs.dhtmlx.com/scheduler/integrations/react/
- Repository: https://github.com/DHTMLX/react-scheduler-examples

## How to start

```bash
npm install
npm start
```

The app starts locally with the public trial wrapper package `@dhtmlx/trial-react-scheduler` pinned to `^7.2.15`.

## Build for production

```bash
npm run build
```

## Notes

- The application source code in this repo is published as an example project.
- `@dhtmlx/trial-react-scheduler` is a commercial trial package. Use it under a valid evaluation or commercial agreement.
